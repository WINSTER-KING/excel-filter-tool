Excel 数据处理工具

表格筛选工具 · 使用说明

像在 Excel 里一样，点击每一列标题进行筛选，实时预览，一键导出并保留原格式。

1这个工具是做什么的

打开一个 Excel 文件（.xlsx 或 .xlsm）后，可以点击每一列的标题进行筛选，实时预览结果，最后把筛选结果另存为一个新的 Excel 文件（保留原表格式）。工具会自动记忆上次的筛选设置，并支持把常用筛选保存为预设。

2两种运行方式

方式 A：直接用打包好的 exe（推荐，无需装任何东西）

  1. 确保电脑上已生成 dist\ExcelFilterTool.exe（见第 3 节「如何打包」）。
  2. 双击运行即可。

方式 B：直接用 Python 运行

需要电脑装有 Python 3.9+，并已安装 openpyxl：

pip install openpyxl
python excel_filter_tool.py

3如何打包成 exe

  1. 把 excel_filter_tool.py、build_exe.bat、app.ico（可选，用于图标）放在同一个文件夹。
  2. 双击 build_exe.bat，脚本会自动装好依赖并打包。
  3. 完成后，可执行文件在 dist\ExcelFilterTool.exe。
首次打包需要联网下载依赖，之后生成的 exe 可以单独复制到任何电脑上双击运行。

4操作步骤

  1. 点左上角「选择 Excel 文件」，选中你的表格文件。
  2. 程序自动识别表头，中间表格实时显示数据；底部状态栏显示「匹配 N 条 / 共 M 条」。
  3. 筛选（像 Excel 一样）：点击某一列的标题（带 ▾ 箭头），弹出该列的筛选窗口，里面可以：
    • 勾选值：勾选要保留的值（默认全选，取消某个值就排除它；同一列勾多个是「或」，多列之间是「且」）。
    • 包含文字：输入文字，只保留该列内容包含这段文字的行（不区分大小写）。
    • 搜索值：值很多时，在最上面的「搜索值」框输入文字快速定位。
    • 「全选 / 清空 / 清除本列筛选」按钮可快速操作。
  4. 正在生效筛选的列，标题会高亮并显示 ●；「重置筛选」按钮可一键恢复全部数据。
  5. 点右上角「导出 Excel」，选择保存位置和文件名，即可得到筛选后的新文件（保留原格式）。

5预设与自动记忆

自动记忆

关闭程序时自动记住当前的表头结构、筛选设置、上次另存目录和文件名模板。下次打开结构相同的文件时，会自动套用上次的筛选；另存对话框也会定位到上次位置。

筛选预设

工具栏的「预设」下拉 + 「保存预设 / 删除预设」按钮，可把当前筛选条件、另存目录、文件名模板一起保存为一个预设，下拉选中即可一键套用。

文件名模板

在预设或文件名设置中，可用占位符自动生成导出文件名：

占位符含义示例
{date}日期2026-08-13
{time}时间1430
{match}匹配条数9

例如 {date}-铁山站-{match}条 会生成 2026-08-13-铁山站-9条.xlsx。

6常见问题

  • 打开文件很慢 / 卡住：数据量很大时读取需要几秒，属正常现象。
  • 导出时提示失败：请确认保存位置没有被其他程序（如 Excel）占用该文件。
  • 预览只有前 200 行：这是为了界面流畅，导出仍会导出全部匹配结果，不影响使用。
  • 套用预设没反应：预设只记录筛选设置，需先打开一个 Excel 文件再套用。

7技术说明

  • 界面使用 Python 自带 tkinter 绘制，苹果浅灰配色 + 圆角按钮，无需额外 GUI 依赖。
  • 数据读写使用 openpyxl，导出时采用「重开源文件 + 删除多余行」的方式，最大程度保留列宽、字体、颜色、公式和打印设置。
  • 配置文件保存在用户目录下的 .excel_filter_tool\config.json，用于记忆和预设；删除该文件即可清除所有记忆。
