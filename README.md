# 表格筛选工具

一个 Windows 桌面小工具：打开 Excel 文件后，像在 Excel 里一样**点击每一列表头**进行筛选，实时预览，一键导出并保留原表格式。

## 功能特性

- 🖱️ **表头下拉筛选**：点击任意列标题，勾选要保留的值（默认全选、取消即排除；同列多选为「或」，多列之间为「且」）
- 🔍 **包含文字筛选**：按某列内容包含的文字过滤（不区分大小写）
- 💾 **自动记忆**：记住上次的表头结构、筛选设置、另存目录和文件名模板，打开结构相同的文件时自动套用
- ⭐ **筛选预设**：把常用筛选 + 另存位置 + 文件名设置保存为预设，一键套用
- 📁 **文件名模板**：`{date}`、`{time}`、`{match}` 占位符自动生成导出文件名
- 🎨 **苹果风界面**：浅灰配色 + 圆角按钮
- 📤 **保留原格式导出**：导出采用「重开源文件 + 删除多余行」的方式，最大程度保留列宽、字体、颜色、公式和打印设置

## 快速开始

### 方式一：直接运行 exe（无需安装任何东西）

前往 [Releases](../../releases) 下载 `ExcelFilterTool.exe`，双击即可运行，无需安装 Python。

### 方式二：用 Python 运行

需要 Python 3.9+：

```bash
pip install openpyxl
python excel_filter_tool.py
```

## 自己打包成 exe

1. 把 `excel_filter_tool.py`、`build_exe.bat`、`app.ico`（可选，用于图标）放在同一文件夹。
2. 双击 `build_exe.bat`，脚本会自动装好依赖并打包。
3. 完成后，可执行文件在 `dist\ExcelFilterTool.exe`。

> 首次打包需要联网下载依赖。生成的 exe 可单独复制到任何 64 位 Windows 电脑上运行。

## 技术栈

- 界面：Python 自带 tkinter（苹果浅灰配色 + 自绘圆角按钮）
- 数据处理：openpyxl
- 打包：PyInstaller（`-F -w --clean` 单文件模式）

## 常见问题

- **预览只有前 200 行？** 为保持界面流畅，预览显示前 200 行，**导出仍会导出全部**匹配结果。
- **杀毒软件误报？** PyInstaller 打包的 exe 偶尔会被误报，加白名单即可。
- **预设/记忆存在哪？** 用户目录下的 `.excel_filter_tool\config.json`，删除该文件即可清除所有记忆。
